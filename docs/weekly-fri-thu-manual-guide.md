# 통합 주간(금~목) 매출 · 특판·지출 수기 가이드

> 코드 작성 전 설계 문서. **§8 결정사항은 확정됨.**
> 대상: 통합(combined) · 특판(`special_sale`) · 수기 지출(`manual_expense`)

---

## 1. 목표

- 통합에서 **주간**으로도 매출을 본다 (금~목 주차 탭).
- **월별 특판·지출은 그대로 유지** — 월별 통합 화면·**월별 다운로드**에만 사용.
- **주간 특판·지출은 별도** — 주간 조회·**주간 다운로드**에만 넣고, **주끼리·월 수기와 겹치지 않음**.
- UI: **1~6주차 탭**(해당 월에 있는 주만) → 탭 안 수기 입력.

주간 경계(업무 규칙) — 예시 **2026년 9월**:

| 주차 | 기간 | 규칙 |
|------|------|------|
| 1주차 | 9.1 ~ 9.3 | 그달 **1일 ~ 첫 목요일** (달 초 잘린 주) |
| 2주차 | 9.4 ~ 9.10 | **금 ~ 목** 완주 |
| 3주차 | 9.11 ~ 9.17 | 금 ~ 목 |
| 4주차 | 9.18 ~ 9.24 | 금 ~ 목 |
| 5주차 | 9.25 ~ 9.30 | 마지막 금 ~ **그달 말일** (달 말 잘린 주) |

핵심: **금요일 시작 ~ 목요일 종료**. ISO(월~일)와 다름.  
탭 라벨 형식: **`1주차(9.1~9.3)`** (확정).

---

## 2. 현재 상태 (As-Is)

| 항목 | 현황 |
|------|------|
| 특판·지출 저장 | `app_settings` · `scope=combined_monthly` · kind `special_sale` / `manual_expense` |
| 버킷 | `{ months: { 'YYYY-MM': { entries: [...] } } }` — **월만** |
| UI | 통합 **월별**일 때만 패널 |
| KPI | 월 조회에 월 엔트리 전체 merge |
| 주간 수기 | **없음** |

월 수기를 주간 기간 조회에 그대로 붙이면 주마다 중복·오염 → **주간용 버킷을 새로 두고, 월 수기는 월 경로에만 쓴다.**

---

## 3. 확정 제품 동작 (To-Be)

### 3.1 두 갈래 수기 (겹치지 않음) — **확정**

| 경로 | 저장 | 화면·KPI | 엑셀 다운로드 |
|------|------|----------|----------------|
| **월별 특판·지출** | 기존 `months['YYYY-MM']` **유지·입력 유지** | 통합 **월별**만 | **월별** 통합 다운에만 포함 |
| **주간 특판·지출** | 신규 `weeks['YYYY-MM-Wn']` | 통합 **주간** 해당 주차만 | **주간** 다운에만 해당 주 entries |

- 월 수기 ≠ 주 수기 합산. **서로 합치지 않음.**
- 주간끼리도 W1 entries는 W2에 안 들어감.

### 3.2 조회 모드

1. **일별** — 기존. 수기 특판·지출 비포함(현행).
2. **주간** — 신규. 기간 = 선택 주차 `from~to`.
3. **월별** — 기존. 월 특판·지출 패널·다운 그대로.

주간 진입 시:

1. 연·월 선택
2. 주차 탭 — 존재하는 주만, **최대 6개 허용** (확정)
3. 라벨: `1주차(9.1~9.3)`, `2주차(9.4~9.10)`, …
4. 본문:
   - **KPI** = 지금 **기간(from~to) 조회했을 때와 동일**한 빅셀·폐쇄몰·채널 집계  
     + **그 주차 주간 특판·지출**만 merge
   - 그 주 **특판 수기** / **수기 지출** 입력

### 3.3 주간 KPI (확정)

```
주간 KPI = period KPI(from~to)  // 현행 통합 기간 필터와 동일 SoT
         + 주간 special_sale[Wn]
         + 주간 manual_expense[Wn]
```

- 월별 `months[...]` 특판·지출은 **주간 KPI·주간 다운에 넣지 않음**.
- 주간 `weeks[...]`는 **월별 KPI·월별 다운에 넣지 않음**.

### 3.4 수기 입력 UX

탭 = 주차. 필드 = 현행과 동일 (특판: 이름·매출·마진 / 지출: 이름·금액).  
행별 일자 없음 — “2주차 탭에 넣음” = `2026-09-W2` 귀속.

---

## 4. 주차 계산 규칙 (금~목)

입력: `YYYY-MM`.

1. 그달 1일 요일 확인.
2. **1주 종료** = 그달 **첫 목요일**.  
   예(2026-09): 9/1(화) → 첫 목 9/3 → `1주차(9.1~9.3)`.
3. 이후 **다음 금 ~ 그 목** 반복.
4. 마지막 주: start가 그달 안이면 `start ~ 말일`.
5. 탭 개수 = 그달 주 수, **1~6** (6주차 달이면 탭 6개).

헬퍼:

- `listFriThuWeeksInMonth('YYYY-MM') → [{ weekIndex, from, to, label }]`
- `label` 예: `1주차(9.1~9.3)` (`M.D~M.D`, 불필요한 0 패딩 없음)
- `weekKey`: `YYYY-MM-W1` … `YYYY-MM-W6`

테스트 고정:

- 2026-09 → 위 표와 동일
- 1일=금요일 → 1주 완주 7일
- 1일=목요일 → 1주 하루
- 6주 발생하는 달 → 탭 6개

## 5. 데이터 모델

### 5.1 Shape (월 유지 + 주 추가)

```text
kind: special_sale | manual_expense
scope: combined_monthly

{
  version: 2,
  months: {
    "2026-09": { entries: [ ... ] }   // 기존 — 월별 전용, 변경 없음
  },
  weeks: {
    "2026-09-W1": { from: "2026-09-01", to: "2026-09-03", entries: [ ... ] },
    "2026-09-W2": { from: "2026-09-04", to: "2026-09-10", entries: [ ... ] },
    ...
  }
}
```

Entry 스키마 동일: 특판 `{ id, name, sales, margin }` / 지출 `{ id, name, amount }`.

기존 데이터: `months`만 있으면 그대로 동작 (마이그레이션 불필요). `weeks`는 빈 객체부터.

### 5.2 Merge / Export

| 조회·다운 | months 수기 | weeks 수기 |
|-----------|-------------|------------|
| 주간 탭 Wn / 주간 엑셀 | ❌ | ✅ 해당 Wn만 |
| 월별 화면 / 월별 엑셀 | ✅ 해당 YYYY-MM | ❌ |
| 일별 | ❌ | ❌ |

서버 by-segment·export도 동일. Stage 2 KPI SQL freeze 비침범(settings merge만).

## 6. UI 스케치

```
통합 → [일별] [주간] [월별]

주간:
  연도 · 월
  [ 1주차(9.1~9.3) ] [ 2주차(9.4~9.10) ] … (최대 6)

  · KPI (기간=해당 주 + 주간 특판·지출)
  · 특판 수기 (주간)
  · 수기 지출 (주간)

월별:
  · 기존과 동일 (월 특판·지출 패널·월 다운)
```

## 7. 구현 단계

| Phase | 내용 |
|-------|------|
| **P0** | `listFriThuWeeksInMonth` + 라벨 `N주차(M.D~M.D)` + 테스트 |
| **P1** | settings에 `weeks` 추가 (months 유지) · hydrate/save |
| **P2** | 통합 주간 모드 · 주차 탭 · from~to = 현행 기간 필터 |
| **P3** | 주간 전용 특판·지출 패널 (월 패널과 분리) |
| **P4** | KPI merge: 주간=period+weeks[Wn] / 월별=months만 · 주간·월별 export 분리 |
| **P5** | UI_BUILD_ID · NAS 배포 |

## 8. 결정사항 (확정)

| # | 결정 |
|---|------|
| 1 | **월별 특판·지출 유지** — 월별 통합·월별 다운 전용 |
| 2 | **주간 특판·지출 신설** — 주간만, 월·다른 주와 **비중복** |
| 3 | **6주차 달 → 탭 6개 허용** |
| 4 | 표기: **`1주차(9.1~9.3)`** |
| 5 | 주간 KPI = **현행 기간 KPI(from~to)와 동일** + **해당 주 수기만** |
| 6 | 기존 months → weeks로 **옮기지 않음** (병행) |

---

## 9. 한 줄 요약

**월 수기는 월 다운용으로 두고, 주간은 금~목 탭(`1주차(9.1~9.3)`…)마다 별도 특판·지출을 넣어 기간 KPI에만 붙인다. 주·월·주간끼리 수기는 겹치지 않는다.**
