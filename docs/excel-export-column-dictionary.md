# 엑셀 내보내기 컬럼 사전

코드 기준으로 엑셀 내보내기 시 생성되는 시트와 컬럼 의미를 정리한 문서입니다.

- 기준 파일:
  - `src/utils/dashboardExporter.js`
  - `src/utils/profitLossReportExporter.js`
  - `src/utils/manualAdExcel.js`
  - `src/utils/integratedKpiExcel.js`
  - `src/constants/salesColumns.js`
- 목적:
  - 사용자 데이터 예시 없이
  - "어떤 시트에 어떤 컬럼이 나오고"
  - "그 컬럼이 코드상 무엇을 의미하는지"
    빠르게 확인하기 위한 문서

## 워크북 시트 구성

| 시트 | 주요 내용 |
| --- | --- |
| `①요약리포트` | 메타 정보 + 수동광고 + 전일/전주/전월 대비 + KPI + 판매방식별 요약 + 일별 요약 |
| `②전일대비 / ②전주대비 / ②전월대비` | 비교 모드별 매출 비교표 |
| `②판매방식별` | 판매방식 집계 |
| `③일별 / ④주별 / ⑤월별` | 기간 버킷 집계 |
| `⑥기간통합` | 일·주·월 추이를 한 시트에 세 블록으로 연속 배치 |
| `⑦스토어별` | 스토어 집계 |
| `⑧상세_판매` | 전체 상세 판매 행 |
| `⑨반품` | 반품 상세 행 |
| `⑩상품순위` | 상세 판매를 매출 기준 상위 200행 정렬 |
| `⑪빅셀_판매 / ⑫빅셀_반품` | 빅셀 호환 한글 헤더 형식 |
| `KPI` | 핵심 KPI 사전식 설명 + 세그먼트 표 |

## ①요약리포트 내부 블록

- 리포트 메타:
  - 플랫폼
  - 판매방식
  - 리포트 형식
  - 생성 시각
  - 데이터 기간
  - 판매 데이터 건수
  - 반품·취소 건수
- 수동광고 블록:
  - 채널·소스별 일자/월별 광고비와 전환매출
- 전일/전주/전월 대비 블록
- 핵심 KPI 블록
- 판매방식별 요약 블록
- 최근 일별 요약 블록

## KPI 시트 내부 블록

- 세그먼트 `매출·수익` 표
- 세그먼트 `광고·판매량` 표
- 핵심 KPI 설명 표
- 반품·취소 집계
- 필요 시 수동광고 블록/안내

## 공통 기간표 컬럼

적용 시트:

- `③일별`
- `④주별`
- `⑤월별`
- `⑥기간통합`
- 통합 `①요약리포트`의 일별 요약

| 컬럼 | 코드상 의미 |
| --- | --- |
| `기간` | 일/주/월 버킷 라벨 |
| `매출` | 해당 기간 매출 합 |
| `원가` | 기간 총원가 |
| `판매수량` | 기간 판매수량 합 |
| `순이익금` | 기간 순이익 합 |
| `순이익률(%)` | `순이익금 ÷ 매출 × 100` |
| `광고비` | 기간 광고비 합 |
| `광고매출` | 광고로 잡힌 매출 |
| `ROAS(광고)(%)` | `광고매출 ÷ 광고비 × 100` |
| `ROAS(전체)(%)` | `전체 매출 ÷ 광고비 × 100` |
| `자연매출` | `매출 - 광고매출` |
| `자연매출 비율(%)` | `자연매출 ÷ 매출 × 100` |

## 판매방식별 시트 컬럼

적용 시트:

- `②판매방식별`
- 통합 `①요약리포트` 내부의 판매방식별 요약 블록

| 컬럼 | 코드상 의미 |
| --- | --- |

| `순이익금` | 집계된 순이익 값 |
| `순이익률(%)` | `순이익금 ÷ 매출 × 100` |
| `광고비` | 판매방식 광고비 합 |
| `광고매출` | 광고매출 합 |
| `ROAS(광고)(%)` | `광고매출 ÷ 광고비 × 100` |
| `ROAS(전체)(%)` | `매출 ÷ 광고비 × 100` |
| `자연매출` | 광고 제외 매출 |
| `자연매출 비율(%)` | `자연매출 ÷ 매출 × 100` |
| `상품행수` | 그 판매방식에 속한 상세 상품행 개수 |
| `매출비중(%)` | `해당 판매방식 매출 ÷ 전체 매출 × 100` |

## 특히 자주 헷갈리는 컬럼

### `순이익금`

- 시트에 따라 의미가 다를 수 있습니다.
  - 원본 상세 순이익
  - 기간 집계 순이익
  - 스토어 집계 순이익
- 따라서 단순히 같은 행의 `매출 - 원가 - 광고비`로 다시 계산한 값이라고 보면 안 됩니다.

### `원가`

- 상세 시트에서는 단가/합계가 분리됩니다.
- 판매방식 집계에서는 일부 스마트스토어 항목이 마진 기준으로 역산될 수 있습니다.

### `광고비`

- 상세 광고값
- 기간 합산 광고값
- 수동광고 적용 총합

같은 이름이라도 시트마다 입력 원천이 다를 수 있습니다.

## 가장 빠른 확인 순서

숫자가 어디서 왔는지 추적할 때는 아래 순서가 가장 빠릅니다.

1. 시트 이름 확인
2. 헤더 종류 확인
   - 기간표
   - 판매방식별
   - 스토어별
   - 상세
   - KPI
3. 위 컬럼 사전에서 의미 확인
